下面给出一套**批量向量化**的反向传播公式，适用于：

* 前 $1\ldots L-1$ 层激活为 **sigmoid**；
* 第 $L$ 层激活为 **softmax**；
* 损失为 **多分类交叉熵**（Cross-Entropy）。

记号（与常见 NumPy 实现对齐）：

* 批大小 $N$；层宽 $(n_0,\dots,n_L)$，其中 $n_0$ 是输入特征数。
* 前向：$A^{[0]}=X$，对每层 $l=1..L$：

  $$
  Z^{[l]} = A^{[l-1]} W^{[l]} + b^{[l]},\quad
  A^{[l]} =
  \begin{cases}
  \sigma\!\left(Z^{[l]}\right) & l=1..L-1\\
  \mathrm{softmax}\!\left(Z^{[l]}\right) & l=L
  \end{cases}
  $$

  其中 $W^{[l]}\in\mathbb{R}^{n_{l-1}\times n_l}$，$b^{[l]}\in\mathbb{R}^{1\times n_l}$。
* 目标用 one-hot 矩阵 $Y\in\mathbb{R}^{N\times n_L}$（若标签是整型索引，计算时临时构造 one-hot 即可）。
* 损失：

  $$
  \mathcal{L} = -\frac{1}{N}\sum_{i=1}^N \sum_{k=1}^{n_L} Y_{ik}\,\log A^{[L]}_{ik}
  $$

---

# 反向传播（梯度与误差项）

### 输出层 $l=L$（softmax + CE 的“神公式”）

$$
\boxed{\;\delta^{[L]} \;=\; A^{[L]} - Y\;}\quad\text{(形状 }N\times n_L\text{)}
$$

$$
\boxed{\; \frac{\partial \mathcal{L}}{\partial W^{[L]}} \;=\; \frac{1}{N}\,(A^{[L-1]})^\top \delta^{[L]} \;}
\qquad
\boxed{\; \frac{\partial \mathcal{L}}{\partial b^{[L]}} \;=\; \frac{1}{N}\,\mathbf{1}^\top \delta^{[L]} \;}
$$

其中 $\mathbf{1}$ 是长度为 $N$ 的全 1 列向量；结果 $\partial\mathcal{L}/\partial b^{[L]}$ 为 $1\times n_L$。

### 隐藏层 $l=L-1,\dots,1$（sigmoid）

$$
\delta^{[l]} \;=\; \big(\,\delta^{[l+1]} (W^{[l+1]})^\top \big)\; \odot\; \sigma'(Z^{[l]})
$$

其中 $\sigma'(Z^{[l]}) = A^{[l]} \odot (1-A^{[l]})$（利用已缓存的 $A^{[l]}$ 更稳）。
对应梯度：

$$
\boxed{\; \frac{\partial \mathcal{L}}{\partial W^{[l]}} \;=\; \frac{1}{N}\,(A^{[l-1]})^\top \delta^{[l]} \;}
\qquad
\boxed{\; \frac{\partial \mathcal{L}}{\partial b^{[l]}} \;=\; \frac{1}{N}\,\mathbf{1}^\top \delta^{[l]} \;}
$$

---

# 与你的 NumPy 实现的形状对齐

* 你使用 $Z = A@W + b$，所以：

  * $A^{[l-1]}$: $(N, n_{l-1})$
  * $W^{[l]}$: $(n_{l-1}, n_l)$
  * $b^{[l]}$: $(1, n_l)$（会沿 batch 维广播）
  * $\delta^{[l]}$: $(N, n_l)$
  * $dW^{[l]} = (A^{[l-1]})^\top \delta^{[l]} / N$: $(n_{l-1}, n_l)$
  * $db^{[l]} = \text{sum}(\delta^{[l]}, \text{axis}=0, \text{keepdims}=True)/N$: $(1, n_l)$

---

# 伪代码（与你的变量名一致）

```python
# cache: 存了 A1...AL, Z1...ZL；A0 = X
A = [A0, A1, ..., AL]
W = [W1, ..., WL]
b = [b1, ..., bL]
Y_onehot = ...  # 由整型 y 构造 (N, nL)

# 输出层
delta_L = A[L] - Y_onehot                 # (N, nL)
dW[L] = A[L-1].T @ delta_L / N            # (n_{L-1}, nL)
db[L] = delta_L.sum(axis=0, keepdims=True) / N  # (1, nL)

# 隐藏层
delta = delta_L
for l in range(L-1, 0, -1):
    delta = (delta @ W[l].T) * (A[l] * (1 - A[l]))  # sigmoid'
    dW[l] = A[l-1].T @ delta / N
    db[l] = delta.sum(axis=0, keepdims=True) / N
```

> 数值稳定性：softmax 用 `e_x = exp(Z - Z.max(axis=1, keepdims=True))`；交叉熵里对概率加 `1e-9` 防 `log(0)`。
> 梯度检查：可用有限差分在小网络上验算上述式子是否正确。
