好，我给你写一个 **三层神经网络**（输入层 → 隐藏层 → 输出层）的 **NumPy + Sigmoid** 完整实现，包含**前向传播**和**反向传播**，并且是可以直接运行的版本。

我们假设结构为：

* 输入层：`n_input` 个特征
* 隐藏层：`n_hidden` 个神经元
* 输出层：`n_output` 个神经元（分类可用 softmax，这里为了简化也用 sigmoid）

---

### 代码实现

```python
import numpy as np

# ====== 激活函数 ======
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_deriv(x):
    return x * (1 - x)  # 输入已经是 sigmoid(x) 的值

# ====== 三层神经网络类 ======
class ThreeLayerNN:
    def __init__(self, n_input, n_hidden, n_output, learning_rate=0.1):
        # 初始化权重（均值0的高斯分布）
        self.W1 = np.random.randn(n_input, n_hidden) * 0.01
        self.b1 = np.zeros((1, n_hidden))
        self.W2 = np.random.randn(n_hidden, n_output) * 0.01
        self.b2 = np.zeros((1, n_output))
        self.lr = learning_rate

    def forward(self, X):
        # 输入层 -> 隐藏层
        self.z1 = np.dot(X, self.W1) + self.b1
        self.a1 = sigmoid(self.z1)

        # 隐藏层 -> 输出层
        self.z2 = np.dot(self.a1, self.W2) + self.b2
        self.a2 = sigmoid(self.z2)

        return self.a2

    def backward(self, X, y):
        m = X.shape[0]

        # 输出层误差 (dL/da2 * da2/dz2)
        delta2 = (self.a2 - y) * sigmoid_deriv(self.a2)
        dW2 = np.dot(self.a1.T, delta2) / m
        db2 = np.sum(delta2, axis=0, keepdims=True) / m

        # 隐藏层误差
        delta1 = np.dot(delta2, self.W2.T) * sigmoid_deriv(self.a1)
        dW1 = np.dot(X.T, delta1) / m
        db1 = np.sum(delta1, axis=0, keepdims=True) / m

        # 梯度下降更新权重
        self.W1 -= self.lr * dW1
        self.b1 -= self.lr * db1
        self.W2 -= self.lr * dW2
        self.b2 -= self.lr * db2

    def train(self, X, y, epochs=1000):
        for i in range(epochs):
            self.forward(X)
            self.backward(X, y)

            if (i + 1) % 100 == 0:
                loss = np.mean((y - self.a2) ** 2)
                print(f"Epoch {i+1}, Loss: {loss:.6f}")

# ====== 测试 ======
if __name__ == "__main__":
    # 生成数据 (XOR 问题)
    X = np.array([[0,0],
                  [0,1],
                  [1,0],
                  [1,1]])
    y = np.array([[0],
                  [1],
                  [1],
                  [0]])

    nn = ThreeLayerNN(n_input=2, n_hidden=4, n_output=1, learning_rate=0.5)
    nn.train(X, y, epochs=10000)

    # 预测
    print("预测结果:")
    print(nn.forward(X))
```

### 公式推导（多层网络 BP）

如果是三层结构：

* **前向传播：**

$$
a^{[1]} = \sigma(W^{[1]} X + b^{[1]})
$$

$$
a^{[2]} = \sigma(W^{[2]} a^{[1]} + b^{[2]})
$$

* **反向传播：**

$$
\delta^{[2]} = (a^{[2]} - y) \odot \sigma'(a^{[2]})
$$

$$
\delta^{[1]} = (W^{[2]} \delta^{[2]}) \odot \sigma'(a^{[1]})
$$

$$
dW^{[2]} = \frac{1}{m} a^{[1]T} \delta^{[2]},\quad db^{[2]} = \frac{1}{m} \sum \delta^{[2]}
$$

$$
dW^{[1]} = \frac{1}{m} X^T \delta^{[1]},\quad db^{[1]} = \frac{1}{m} \sum \delta^{[1]}
$$
