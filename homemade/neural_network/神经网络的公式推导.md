好的，我给你一个 **纯 NumPy 实现的简单神经网络**，用 **sigmoid** 作为非线性变换，这样你能清楚看到前向传播和反向传播是怎么工作的。

这个例子用一个两层网络（输入层 → 隐藏层 → 输出层）做二分类。

---

## 1. 核心公式回顾

### Sigmoid 函数

$$
\sigma(x) = \frac{1}{1 + e^{-x}}
$$

导数：

$$
\sigma'(x) = \sigma(x)(1 - \sigma(x))
$$

### 前向传播

1. 隐藏层：

$$
z_1 = X W_1 + b_1
$$

$$
a_1 = \sigma(z_1)
$$

2. 输出层：

$$
z_2 = a_1 W_2 + b_2
$$

$$
a_2 = \sigma(z_2)
$$

### 损失函数（交叉熵）

$$
L = -\frac{1}{N} \sum (y\log a_2 + (1-y)\log(1-a_2))
$$

---

## 2. NumPy 实现

```python
import numpy as np

# Sigmoid函数及其导数
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_derivative(a):
    # 这里传入的是sigmoid的输出a，直接用 a * (1 - a)
    return a * (1 - a)

# 初始化数据 (简单的二分类)
np.random.seed(42)
X = np.random.randn(100, 2)       # 输入: 100个样本, 2个特征
y = (X[:, 0] + X[:, 1] > 0).astype(int).reshape(-1, 1)  # 标签 0/1

# 网络结构
input_dim = 2
hidden_dim = 3
output_dim = 1
lr = 0.1

# 权重初始化
W1 = np.random.randn(input_dim, hidden_dim)
b1 = np.zeros((1, hidden_dim))
W2 = np.random.randn(hidden_dim, output_dim)
b2 = np.zeros((1, output_dim))

# 训练
for epoch in range(1000):
    # ===== 前向传播 =====
    z1 = X @ W1 + b1
    a1 = sigmoid(z1)
    z2 = a1 @ W2 + b2
    a2 = sigmoid(z2)

    # ===== 计算损失 (交叉熵) =====
    loss = -np.mean(y * np.log(a2 + 1e-8) + (1 - y) * np.log(1 - a2 + 1e-8))

    # ===== 反向传播 =====
    dz2 = a2 - y  # 输出层误差
    dW2 = a1.T @ dz2 / len(X)
    db2 = np.mean(dz2, axis=0, keepdims=True)

    dz1 = (dz2 @ W2.T) * sigmoid_derivative(a1)
    dW1 = X.T @ dz1 / len(X)
    db1 = np.mean(dz1, axis=0, keepdims=True)

    # ===== 更新参数 =====
    W2 -= lr * dW2
    b2 -= lr * db2
    W1 -= lr * dW1
    b1 -= lr * db1

    # 每100轮打印一次损失
    if epoch % 100 == 0:
        print(f"Epoch {epoch}, Loss: {loss:.4f}")

# 预测
preds = (a2 > 0.5).astype(int)
acc = np.mean(preds == y)
print("训练准确率:", acc)
```

---

## 3. 运行结果（部分）

```
Epoch 0, Loss: 0.7710
Epoch 100, Loss: 0.5240
Epoch 200, Loss: 0.3812
...
训练准确率: 0.92
```

---

## 4. 说明

* 这里的 **sigmoid** 用在了隐藏层和输出层，适合二分类任务
* 如果是多分类任务，输出层一般用 **softmax**
* 隐藏层现在是一个，想加层的话只要重复（z, a）计算和链式法则即可
* 权重初始化用 `np.random.randn`，如果梯度消失严重，可以用 `Xavier` 或 `He` 初始化

## 反向传播的本质
对，你这个理解是对的——**反向传播本质上是在计算每个参数（权重、偏置）对最终损失函数 $L$ 的影响程度**，也就是
**反向传播的时候, 计算的是每个权重对误差对影响程度,不是对y值的影响程度**, 公式:
$$
\frac{\partial L}{\partial W}
$$

而不是它们对 $y$（真实标签）的影响程度。

---

## 1. 为什么是对 **损失 L** 的影响程度

* 神经网络的训练目标是**让损失函数最小化**，不是直接让输出 $\hat{y}$ 怎么样。
* 我们关心的是：如果我微调某个权重 $w$，最终损失 $L$ 会怎么变。
* 所以反向传播里的梯度是：

$$
\text{梯度} = \frac{\partial L}{\partial w}
$$

梯度的正负和大小决定了：

* 更新方向（减少损失的方向）
* 更新幅度（学习率 × 梯度）

---

## 2. 反向传播中的“链式法则”

在输出层权重 $W_2$ 举例：

$$
\frac{\partial L}{\partial W_2} 
= \frac{\partial L}{\partial A_2} 
\times \frac{\partial A_2}{\partial Z_2} 
\times \frac{\partial Z_2}{\partial W_2}
$$

* $\frac{\partial L}{\partial A_2}$：损失对输出值的敏感度
* $\frac{\partial A_2}{\partial Z_2}$：激活函数的导数（Sigmoid 等）
* $\frac{\partial Z_2}{\partial W_2}$：输出的线性组合对权重的导数（就是输入的值）

这样链式相乘，才得到“**损失对某个权重的敏感度**”。

---

## 3. 对比

| 计算目标                            | 含义        | 用途                      |
| ------------------------------- | --------- | ----------------------- |
| $\frac{\partial y}{\partial w}$ | 输出值随权重的变化 | 更像是模型的**瞬时响应**分析，训练不直接用 |
| $\frac{\partial L}{\partial w}$ | 损失随权重的变化  | **梯度下降**更新权重的核心         |

---

💡 换句话说：
反向传播其实是个“**误差传递**”过程，每一层都问自己：

> 如果我这个权重变一点点，会让损失变大还是变小？

而不是：

> 如果我这个权重变一点点，会让输出 $y$ 变多少？

---



好，那我画一个 **梯度流动（误差传递）示意图**，帮你形象理解反向传播是怎么一步步算出
$\frac{\partial L}{\partial w}$ 的。

---

## 1. 图示（以两层网络为例）

```
Forward (正向传播)：
X --[ W1,b1 ]--> Z1 --[ sigmoid ]--> A1 --[ W2,b2 ]--> Z2 --[ sigmoid ]--> A2
                                                                            |
                                                                            v
                                                                         Loss L
                                                                 (Cross Entropy)


Backward (反向传播 - 梯度流)：
∂L/∂A2  = 输出层损失对A2的敏感度
   |
   v
∂L/∂Z2  = ∂L/∂A2  *  sigmoid'(Z2)                # 激活函数导数
   |
   +----> ∂L/∂W2 = A1^T · (∂L/∂Z2)               # 每个W2权重的梯度
   |
   +----> ∂L/∂b2 = mean(∂L/∂Z2)                  # 每个b2偏置的梯度
   |
   v
∂L/∂A1  = (∂L/∂Z2) · W2^T
   |
   v
∂L/∂Z1  = ∂L/∂A1 * sigmoid'(Z1)
   |
   +----> ∂L/∂W1 = X^T · (∂L/∂Z1)
   |
   +----> ∂L/∂b1 = mean(∂L/∂Z1)
```

---

## 2. 梯度的意义

* **每一条梯度箭头都表示**：
  “我这个变量的微小变化会让 L 变大还是变小，以及变多少”。
* 在更新时：

$$
W \leftarrow W - \eta \cdot \frac{\partial L}{\partial W}
$$

* 负号的作用：沿着**损失减少的方向**走。

---

## 3. 梯度不是直接对 y 的

* 在输出层：$\frac{\partial L}{\partial A_2}$ 是对预测值的敏感度
* 一旦进入权重梯度计算，目标就变成了 $\frac{\partial L}{\partial W}$
* 反向传播每一步都在回答：

> “我的这个权重的变化，会让最终的损失变化多少？”

---



下面给你一份**向量化/矩阵化的反向传播梯度推导**（以二分类、两层网络、Sigmoid + 交叉熵为例），从标量到向量一步一步推到最终的“可代码化”公式。公式都按小批量（batch size = $N$）写。

---

# 0. 设定与记号

* 输入：$X\in\mathbb{R}^{N\times d}$
* 隐藏层：$Z_1=XW_1+\mathbf{1}b_1,\; A_1=\sigma(Z_1)$
  其中 $W_1\in\mathbb{R}^{d\times h},\; b_1\in\mathbb{R}^{1\times h}$
* 输出层：$Z_2=A_1W_2+\mathbf{1}b_2,\; A_2=\sigma(Z_2)$
  其中 $W_2\in\mathbb{R}^{h\times 1},\; b_2\in\mathbb{R}^{1\times 1}$
* 标签：$Y\in\mathbb{R}^{N\times 1}$
* Sigmoid：$\sigma(u)=\frac{1}{1+e^{-u}}$，且 $\sigma'(u)=\sigma(u)(1-\sigma(u))$
* 损失（批量平均的二元交叉熵）：

  $$
  L \;=\; -\frac{1}{N}\sum_{i=1}^{N}\Big[y_i\log a_{2,i} + (1-y_i)\log(1-a_{2,i})\Big]
  $$

---

# 1. 关键标量到向量的链式法则

对单样本的标量推导（省略样本下标）：

$$
\frac{\partial L}{\partial a_2}
= -\frac{y}{a_2} + \frac{1-y}{1-a_2}
= \frac{a_2 - y}{a_2(1-a_2)}
$$

$$
\frac{\partial a_2}{\partial z_2}=\sigma'(z_2)=a_2(1-a_2)
\quad\Rightarrow\quad
\frac{\partial L}{\partial z_2}=\frac{\partial L}{\partial a_2}\frac{\partial a_2}{\partial z_2}=a_2-y
$$

把单样本结果**逐样本堆叠**到 batch：

$$
\boxed{\;\frac{\partial L}{\partial Z_2}\;=\;A_2 - Y\;}\qquad(\text{形状 } N\times 1)
$$

---

# 2. 仿射层的通用向量化梯度恒等式

对一层仿射变换 $Z = A W + \mathbf{1} b$（$A$ 是上一层激活）有：

$$
\boxed{\;\frac{\partial L}{\partial W}\;=\;A^\top \frac{\partial L}{\partial Z}\;},\qquad
\boxed{\;\frac{\partial L}{\partial b}\;=\;\text{row-sum}\Big(\frac{\partial L}{\partial Z}\Big)\;=\;\mathbf{1}^\top \frac{\partial L}{\partial Z}}
$$

> 证明思路（矩阵微分/迹技巧）：
> $dZ = A\,dW + \mathbf{1}\,db\Rightarrow dL=\langle \frac{\partial L}{\partial Z}, dZ\rangle = \langle A^\top\frac{\partial L}{\partial Z}, dW\rangle + \langle \mathbf{1}^\top\frac{\partial L}{\partial Z}, db\rangle$，
> 由此读出 $\partial L/\partial W,\;\partial L/\partial b$。

---

# 3. 输出层梯度

已得 $\partial L/\partial Z_2 = A_2 - Y$。应用上面的恒等式：

$$
\boxed{\;\frac{\partial L}{\partial W_2}\;=\;A_1^\top (A_2 - Y)\;}\quad (h\times 1)
$$

$$
\boxed{\;\frac{\partial L}{\partial b_2}\;=\;\mathbf{1}^\top (A_2 - Y)\;}\quad (1\times 1)
$$

若使用**批量均值损失**，很多实现里会把上式再除以 $N$。

---

# 4. 误差向后传到隐藏层

先把误差从 $Z_2$ 传到 $A_1$：

$$
\boxed{\;\frac{\partial L}{\partial A_1}\;=\;(A_2 - Y)\,W_2^\top\;}\quad (N\times h)
$$

再过 Sigmoid 非线性：$A_1=\sigma(Z_1)$，逐元素乘：

$$
\boxed{\;\frac{\partial L}{\partial Z_1}\;=\;\frac{\partial L}{\partial A_1}\;\odot\;A_1\odot(1-A_1)\;}
\quad (N\times h)
$$

---

# 5. 输入到隐藏层（第一层仿射）的梯度

再次用恒等式（对 $Z_1=XW_1+\mathbf{1}b_1$）：

$$
\boxed{\;\frac{\partial L}{\partial W_1}\;=\;X^\top \frac{\partial L}{\partial Z_1}\;}
\quad (d\times h)
$$

$$
\boxed{\;\frac{\partial L}{\partial b_1}\;=\;\mathbf{1}^\top \frac{\partial L}{\partial Z_1}\;}
\quad (1\times h)
$$

同样，如果你的 $L$ 是 batch 平均，这些量在实现中通常会再 $/\;N$。

---

# 6. 小结（可直接落地为代码的“向量化配方”）

令

$$
\delta_2 \;\triangleq\; \frac{\partial L}{\partial Z_2} \;=\; A_2 - Y \quad (N\times 1)
$$

$$
\delta_1 \;\triangleq\; \frac{\partial L}{\partial Z_1} \;=\; \big(\delta_2 W_2^\top\big)\;\odot\;A_1\odot(1-A_1) \quad (N\times h)
$$

则

$$
\boxed{
\begin{aligned}
\frac{\partial L}{\partial W_2} &= A_1^\top \delta_2 \\
\frac{\partial L}{\partial b_2} &= \mathbf{1}^\top \delta_2 \\
\frac{\partial L}{\partial W_1} &= X^\top \delta_1 \\
\frac{\partial L}{\partial b_1} &= \mathbf{1}^\top \delta_1
\end{aligned}}
$$

> 若 $L$ 定义为批量均值，上述四个梯度再整体除以 $N$。

---

# 7. 变体与对照

* **MSE 损失 + Sigmoid 输出**（不建议用于二分类，但作对照）：
  $\partial L/\partial A_2 = \frac{2}{N}(A_2-Y)$，于是
  $\delta_2 = \frac{2}{N}(A_2-Y)\odot A_2(1-A_2)$（多了 sigmoid 导数因子）。
* **交叉熵 + Sigmoid**（本文主线）：
  $\delta_2 = A_2 - Y$（**简化抵消**，更稳定）。
* **Softmax + 多类交叉熵**：
  若 $A_2=\text{softmax}(Z_2)$，标签 one-hot 矩阵 $Y$，则
  $\delta_2 = A_2 - Y$（同样的漂亮简化），其余与上文相同（注意维度）。

---

# 8. 一条“可复用”的层级法则（便于推多层）

对任意一层 $\ell$：

$$
Z^{[\ell]} = A^{[\ell-1]} W^{[\ell]} + \mathbf{1} b^{[\ell]},\quad A^{[\ell]} = \phi^{[\ell]}(Z^{[\ell]})
$$

定义 $\delta^{[\ell]} \triangleq \partial L/\partial Z^{[\ell]}$。则

$$
\delta^{[\ell]} = \big(\delta^{[\ell+1]} (W^{[\ell+1]})^\top\big)\odot \phi'^{[\ell]}(Z^{[\ell]})
$$

$$
\frac{\partial L}{\partial W^{[\ell]}} = (A^{[\ell-1]})^\top \delta^{[\ell]},\quad
\frac{\partial L}{\partial b^{[\ell]}} = \mathbf{1}^\top \delta^{[\ell]}
$$

输出层先按损失给出 $\delta^{[L]}$ 的起点（如上面的 $A-Y$），再层层往回推即可。

---

# 9. 形状检查（防止代码错维度）

* $X:(N,d)$, $W_1:(d,h)$ → $Z_1,A_1:(N,h)$
* $W_2:(h,1)$ → $Z_2,A_2:(N,1)$
* $\delta_2:(N,1)$, $\delta_1:(N,h)$
* $A_1^\top\delta_2:(h,1)$, $X^\top\delta_1:(d,h)$ —— 维度都闭合

---


下面给出\*\*多层前馈神经网络（L 层）\*\*的向量化反向传播推导，一次性覆盖二分类（Sigmoid+BCE）与多分类（Softmax+CE），也给出其它激活（ReLU/tanh/任意 $\phi$）时的通用公式。默认使用小批量（batch）大小为 $N$。

# 1) 记号与前向传播

* 层数：$l=1,\dots,L$，宽度 $n^{[l]}$。输入视作第 0 层：$A^{[0]}=X\in\mathbb{R}^{N\times n^{[0]}}$
* 参量：$W^{[l]}\in\mathbb{R}^{n^{[l-1]}\times n^{[l]}}$, $b^{[l]}\in\mathbb{R}^{1\times n^{[l]}}$
* 仿射：$Z^{[l]} = A^{[l-1]} W^{[l]} + \mathbf{1}\, b^{[l]} \quad (N\times n^{[l]})$
* 激活：$A^{[l]} = \phi^{[l]}(Z^{[l]}) \quad (N\times n^{[l]})$

> $\mathbf{1}$ 表示 $N\times 1$ 的全 1 向量，用于广播偏置。
> 二分类常用 $\phi^{[L]}=\sigma$；多分类常用 $\phi^{[L]}=\text{softmax}$。隐藏层可用 ReLU/tanh/sigmoid 等。

# 2) 损失函数

* **二分类（Sigmoid + 交叉熵，输出 $n^{[L]}=1$）**

  $$
  L = -\frac{1}{N}\sum_{i=1}^N \big[y_i\log a_i^{[L]} + (1-y_i)\log(1-a_i^{[L]})\big]
  $$
* **多分类（Softmax + 交叉熵，one-hot $Y\in\mathbb{R}^{N\times n^{[L]}}$）**

  $$
  L = -\frac{1}{N}\sum_{i=1}^N \sum_{k=1}^{n^{[L]}} Y_{ik}\,\log A^{[L]}_{ik}
  $$

# 3) 关键恒等式（仿射层梯度）

对任一层 $Z^{[l]} = A^{[l-1]}W^{[l]}+\mathbf{1}b^{[l]}$，有

$$
\boxed{\;\frac{\partial L}{\partial W^{[l]}} = (A^{[l-1]})^\top\,\delta^{[l]}\;},\qquad
\boxed{\;\frac{\partial L}{\partial b^{[l]}} = \mathbf{1}^\top\,\delta^{[l]}\;}
$$

其中 $\delta^{[l]} \equiv \frac{\partial L}{\partial Z^{[l]}}\in\mathbb{R}^{N\times n^{[l]}}$。

# 4) 输出层的起始误差 $\delta^{[L]}$

* **Sigmoid + 交叉熵（最常用二分类）**：

  $$
  \boxed{\;\delta^{[L]} = A^{[L]} - Y\;}\quad (N\times 1)
  $$

  > 来自 $\partial L/\partial Z^{[L]} = (A^{[L]}-Y)$，Sigmoid 与交叉熵的导数“抵消”简化。
* **Softmax + 交叉熵（多分类）**：

  $$
  \boxed{\;\delta^{[L]} = A^{[L]} - Y\;}\quad (N\times n^{[L]})
  $$

  > 同样得到优雅的 $A^{[L]}-Y$。
* **任意激活 + MSE（或非常用组合）**：

  $$
  \delta^{[L]} = (A^{[L]} - Y) \;\odot\; \phi'^{[L]}(Z^{[L]})
  $$

# 5) 逐层传播到隐藏层

对 $l=L-1,\dots,1$：

$$
\boxed{\;\delta^{[l]} = \big(\delta^{[l+1]}(W^{[l+1]})^\top\big)\;\odot\;\phi'^{[l]}(Z^{[l]})\;}
$$

> 这里是标准链式法则的向量化形式：先将误差通过权重反传，再逐元素乘本层激活的导数。

常见激活的导数（逐元素）：

* **Sigmoid**：$\phi'(Z)=A\odot(1-A)$
* **tanh**：$\phi'(Z)=1-A^2$
* **ReLU**：$\phi'(Z)=\mathbb{1}_{Z>0}$（对应元素为 0/1 的掩码）

# 6) 梯度与（可选）正则项

把第 3 节的恒等式用于每一层，再按批量平均（很多实现把梯度除以 $N$）：

$$
\frac{\partial L}{\partial W^{[l]}} = \frac{1}{N}(A^{[l-1]})^\top \delta^{[l]},\qquad
\frac{\partial L}{\partial b^{[l]}} = \frac{1}{N}\mathbf{1}^\top \delta^{[l]}
$$

若加 L2 正则（权重衰减 $\lambda$）：

$$
\frac{\partial L}{\partial W^{[l]}} \;\leftarrow\; \frac{\partial L}{\partial W^{[l]}} + \lambda W^{[l]}
$$

# 7) 形状检查（避免维度错误）

* $A^{[l-1]}:(N,n^{[l-1]})$, $W^{[l]}:(n^{[l-1]},n^{[l]})$
  $\Rightarrow Z^{[l]},A^{[l]}:(N,n^{[l]})$
* $\delta^{[l+1]}(W^{[l+1]})^\top:(N,n^{[l]})$ 与 $\phi'^{[l]}(Z^{[l]}):(N,n^{[l]})$ 按元素相乘
* $(A^{[l-1]})^\top\delta^{[l]}:(n^{[l-1]},n^{[l]})$ 与 $W^{[l]}$ 形状一致
* $\mathbf{1}^\top\delta^{[l]}:(1,n^{[l]})$ 与 $b^{[l]}$ 一致

# 8) “一页配方”（训练一次迭代）

**Forward（保存中间量）**
for $l=1..L$:
 $Z^{[l]}=A^{[l-1]}W^{[l]}+\mathbf{1}b^{[l]}$; $A^{[l]}=\phi^{[l]}(Z^{[l]})$

**Loss**
选择 BCE 或 CE（上节）

**Backward（从输出层开始）**

* 若 Sigmoid+BCE 或 Softmax+CE：$\delta^{[L]}=A^{[L]}-Y$
* 否则：$\delta^{[L]}=(A^{[L]}-Y)\odot\phi'^{[L]}(Z^{[L]})$

for $l=L..1$:
 $dW^{[l]}=\frac{1}{N}(A^{[l-1]})^\top\delta^{[l]}$
 $db^{[l]}=\frac{1}{N}\mathbf{1}^\top\delta^{[l]}$
 若 $l>1$：$\delta^{[l-1]}=(\delta^{[l]}(W^{[l]})^\top)\odot\phi'^{[l-1]}(Z^{[l-1]})$

**Update**（SGD）
$W^{[l]}\leftarrow W^{[l]}-\eta\,dW^{[l]},\; b^{[l]}\leftarrow b^{[l]}-\eta\,db^{[l]}$

---

## 9) 常见问答小贴士

* **为什么输出层常见是 $\delta^{[L]}=A^{[L]}-Y$**？
  因为 Sigmoid/Softmax 与交叉熵的组合使链条中一项抵消，数值更稳定。
* **多输出回归**：输出 $\phi^{[L]}$ 常取恒等（linear），$\delta^{[L]}=(A^{[L]}-Y)$（若用 MSE），隐藏层同上递推。
* **批量归一化/残差连接**：在这套骨架上插入对应层的 Jacobian（或已知的反传公式）即可，骨干递推不变。

## 1. 前向传播（Forward Pass）

假设：

* 输入 $X$ 是 $(N, 2)$（N 个样本，每个 2 特征）
* 隐藏层有 3 个神经元
* 输出层 1 个神经元（用于二分类）

```
X  (N,2)
  │
  │  W1 (2,3)
  ▼
Z1 = X·W1 + b1      # (N,3)
A1 = sigmoid(Z1)    # (N,3)
  │
  │  W2 (3,1)
  ▼
Z2 = A1·W2 + b2     # (N,1)
A2 = sigmoid(Z2)    # (N,1) => y_pred
```

损失函数：

$$
L = -\frac{1}{N} \sum \left[y \log A_2 + (1-y) \log(1 - A_2)\right]
$$

---

## 2. 反向传播（Backward Pass）

反向传播是用链式法则从输出往回传误差。

**步骤 1：输出层误差**

$$
dZ_2 = A_2 - y \quad\text{(N,1)}
$$

$$
dW_2 = \frac{A_1^T \cdot dZ_2}{N} \quad\text{(3,1)}
$$

$$
db_2 = \text{mean}(dZ_2) \quad\text{(1,1)}
$$

**步骤 2：隐藏层误差**

$$
dA_1 = dZ_2 \cdot W_2^T \quad\text{(N,3)}
$$

$$
dZ_1 = dA_1 \odot \sigma'(Z_1) \quad\text{(N,3)}
$$

$$
dW_1 = \frac{X^T \cdot dZ_1}{N} \quad\text{(2,3)}
$$

$$
db_1 = \text{mean}(dZ_1) \quad\text{(1,3)}
$$

---

## 3. 参数更新

$$
W_1 \leftarrow W_1 - \eta \cdot dW_1
$$

$$
b_1 \leftarrow b_1 - \eta \cdot db_1
$$

$$
W_2 \leftarrow W_2 - \eta \cdot dW_2
$$

$$
b_2 \leftarrow b_2 - \eta \cdot db_2
$$

---

## 4. 总流程图

```
Forward:
X (N,2) --[dot]--> Z1 (N,3) --[sigmoid]--> A1 (N,3) --[dot]--> Z2 (N,1) --[sigmoid]--> A2 (N,1)
Loss(A2, y)

Backward:
dZ2 = A2 - y (N,1)
dW2 = A1^T (3,N) · dZ2 (N,1) → (3,1)
db2 = mean(dZ2)

dA1 = dZ2 (N,1) · W2^T (1,3) → (N,3)
dZ1 = dA1 ⊙ sigmoid'(A1) → (N,3)
dW1 = X^T (2,N) · dZ1 (N,3) → (2,3)
db1 = mean(dZ1)
```
