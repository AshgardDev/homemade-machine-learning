在三维空间中，一个平面的方程通常表示为 $ Ax + By + Cz + D = 0 $。其中，$(A, B, C)$ 是该平面的法向量。以下是为什么 $(A, B, C)$ 是法向量的详细解释：

### **1. 平面法向量的定义**
法向量是垂直于平面的向量。对于平面 $ Ax + By + Cz + D = 0 $，其法向量是一个与平面内所有向量垂直的向量。换句话说，平面上任意一条直线的方向向量与法向量的点积为零。

### **2. 推导法向量为 $(A, B, C)$**
平面方程 $ Ax + By + Cz + D = 0 $ 的几何意义是：对于平面上的任意点 $(x, y, z)$，它满足该方程。假设平面上的两个点为 $ P_1(x_1, y_1, z_1) $ 和 $ P_2(x_2, y_2, z_2) $，则向量 $\vec{v} = (x_2 - x_1, y_2 - y_1, z_2 - z_1)$ 是平面上的一个方向向量。

如果向量 $\vec{n} = (A, B, C)$ 是平面的法向量，那么它必须与平面上的任意方向向量垂直，即：
$
\vec{n} \cdot \vec{v} = A(x_2 - x_1) + B(y_2 - y_1) + C(z_2 - z_1) = 0
$

因为 $ P_1 $ 和 $ P_2 $ 都在平面上，它们满足平面方程：
$
Ax_1 + By_1 + Cz_1 + D = 0
$
$
Ax_2 + By_2 + Cz_2 + D = 0
$

将两方程相减：
$
A(x_2 - x_1) + B(y_2 - y_1) + C(z_2 - z_1) + D - D = 0
$
$
A(x_2 - x_1) + B(y_2 - y_1) + C(z_2 - z_1) = 0
$

这正是 $\vec{n} \cdot \vec{v} = 0$，表明向量 $(A, B, C)$ 与平面上的任意方向向量垂直，因此 $(A, B, C)$ 是平面的法向量。

### **3. 几何直观解释**
- 平面方程 $ Ax + By + Cz + D = 0 $ 可以看作是向量 $(A, B, C)$ 与点 $(x, y, z)$ 到某个固定点的向量之间的点积关系。
- 具体来说，平面可以表示为：
  $
  (A, B, C) \cdot (x - x_0, y - y_0, z - z_0) = 0
  $
  其中 $(x_0, y_0, z_0)$ 是平面上的一个点。这表明 $(A, B, C)$ 是垂直于平面的向量。

### **4. 法向量的性质**
- **唯一性（方向）**：法向量 $(A, B, C)$ 的方向是唯一的，但其长度（模）可以任意缩放。例如，$(kA, kB, kC)$（$k \neq 0$）也是同一平面的法向量。
- **归一化**：如果需要单位法向量，可以通过 $\left( \frac{A}{\sqrt{A^2 + B^2 + C^2}}, \frac{B}{\sqrt{A^2 + B^2 + C^2}}, \frac{C}{\sqrt{A^2 + B^2 + C^2}} \right)$ 得到。

### **5. 示例**
假设平面方程为 $ 2x + 3y - 4z + 5 = 0 $：
- 法向量为 $(2, 3, -4)$。
- 平面上的任意方向向量（如通过平面上的两点计算）与 $(2, 3, -4)$ 的点积为零。
- 例如，取平面上的两点（通过解方程得到），验证方向向量与 $(2, 3, -4)$ 垂直。

### **6. 注意事项**
- 如果 $ A = B = C = 0 $，方程不表示一个平面（无意义）。
- 法向量 $(A, B, C)$ 的方向决定了平面的朝向，改变 $ D $ 仅平移平面，不改变法向量。

### **总结**
平面 $ Ax + By + Cz + D = 0 $ 的法向量是 $(A, B, C)$，因为它与平面上的任意方向向量垂直。这一性质直接从平面方程的数学形式推导得出，且具有明确的几何意义。
